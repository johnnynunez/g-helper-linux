# ProArt P14 Dual Platform Implementation Plan

> For agentic workers: execute independent Windows and Linux backend streams with TDD; parent implements and integrates the Linux frontend, followed by one independent whole-change review.

Goal: publish a native Linux fork with actual P14 readings/controls and a narrowly scoped tested Windows support branch.
Architecture: keep upstream Windows implementation; add a Python GTK4 frontend with a testable standard-library hardware backend in linux/. Unsupported hardware features are explicit, never simulated.
Tech Stack: C#/.NET 10 Windows; Python 3.10+ / GTK4 on Linux.
Spec: docs/superpowers/specs/2026-10-26-proart-p14-design.md

## Global Constraints
No power-limit guessing, no automatic hardware writes, no manual fan/EC writes, no serial/product-key collection, no root services. Missing values are null. Only exact ASUS keyboard hardware/report descriptors may receive explicit keyboard commands. Preserve upstream source/license.

## Review Focus
- Partial/malformed sysfs data or NVIDIA N/A: null with useful warnings, never crash or invented zero.
- Hardware disconnect/permission failures: visible errors, no broad fallback writes.
- Unknown models/devices/descriptors: reject HID writes.
- UI timers/concurrent refresh: responsive, one collector, no implicit writes.
- Model matching: no accidental P14 power limits or other-family changes.

## Task 2: Linux backend
Files: linux/ghelper_linux/backend.py, hid.py; linux/tests/test_backend.py and test_hid.py.
Interfaces: LinuxBackend(sys_root=Path('/sys'), dev_root=Path('/dev'), runner=None). snapshot() -> JSON-serializable dict with identity, gpu, battery, sensors, capabilities, warnings. GPU keys name, temperature_c, utilization_percent, power_w, memory_used_mib, memory_total_mib. Battery keys capacity_percent, status, power_w, charge_limit_percent. Sensors are {label, kind, value, unit}. Capabilities keys platform_profile, charge_limit, keyboard_brightness, fn_lock, each a dict with available, writable, value, choices, reason; keyboard brightness also max. identity keys vendor, model, architecture. Explicit methods set_platform_profile(value: str), set_charge_limit(value: int), set_keyboard_brightness(value: int), set_fn_lock(enabled: bool) -> None; verify writes or raise clear error. No writes from snapshot.
